# Security Policy 🛡️

We take the security and privacy of **Data Burner** seriously. If you believe you have found a security vulnerability, please follow the guidelines below.

---

## 🔒 Supported Versions

The following table lists the project versions currently receiving security updates:

| Version | Supported |
| ------- | --------- |
| 1.x (Latest `main`) | :white_check_mark: |
| < 1.0 | :x: |

---

## 🚨 Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report security issues privately:

1. Email the project maintainers or submit a private security advisory on GitHub if available.
2. Provide a clear description of the issue, potential impact, and steps to reproduce.
3. Allow up to 48 hours for an initial response from maintainers.

---

## 🛡️ Best Practices & Scope

- **Network Consumption:** Data Burner is designed to stream data over HTTP/HTTPS connections for stress testing. Ensure user consent and network quota safety.
- **Dependencies:** We actively audit and update dependencies to prevent security vulnerabilities.
